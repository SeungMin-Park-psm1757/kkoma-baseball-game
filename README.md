# 꼬마 야구단

정우·세연·토리와 함께 타이밍 타격을 연습하는 한국어 웹 야구 게임입니다.

GitHub Pages에서 정적 HTML·CSS·JavaScript로 실행됩니다.

- 배경별 베이스 좌표에 맞춰 수비·주루 모션이 표시됩니다.
- 내야·외야 타구는 주자의 도착 시각과 수비 포구·송구 시각을 비교해 세이프·아웃·병살을 판정합니다.
- 외야수가 먼저 1루로 송구하고, 장타에서는 1루수→2루수→3루수 순서로 중계 플레이합니다.
- 주자는 일정한 속도로 달리고 마지막 베이스에서만 슬라이딩합니다.
- 삼진, 아웃, 세이프, 주자 이동 때 화면 효과와 효과음이 재생됩니다.
- 상대편은 1단계 파랑, 2단계 빨강, 3·4단계 동물, 5·6단계 꼬마 악마 테마로 바뀝니다.
- Google Flow용 배경음악·효과음 프롬프트는 [GOOGLE_FLOW_AUDIO_PROMPTS.md](GOOGLE_FLOW_AUDIO_PROMPTS.md)에 정리되어 있습니다.
